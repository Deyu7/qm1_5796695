# Bank Marketing Exercise

QM1 homework, week 7. Deyu Wang (5796695)

Does the proportion of people subscribing to a term deposit differ by month? Data are the telephone marketing campaigns of a Portuguese bank, May 2008 to November 2010, from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/222/bank+marketing).

| File | What it is |
|:---|:---|
| `bank-additional-full.csv` | Raw data |
| `bank_marketing.Rmd` | Replication code, going through the tasks in order |
| `bank_marketing.html` | Knitted replication code |
| `bank_marketing_writeup.Rmd` | Source for the write-up |
| `bank_marketing_writeup.docx` | The write-up (no R code) |
| `makefile` | `make all` rebuilds the .html and .docx |

Needs `tidyverse`, `emmeans`, `knitr` and `rmarkdown`.
