# Bike Sharing Regression Exercise

QM1 homework, week 5. Deyu Wang (5796695)

How does the weather (temperature and wind speed) affect daily bike hire? Data are the Capital Bikeshare daily data for 2011-2012 from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).

| File | What it is |
|:---|:---|
| `day.csv` | Raw data |
| `bike_sharing_regression.Rmd` | Replication code, answering tasks 1 to 14 |
| `bike_sharing_regression.html` | Knitted replication code |
| `bike_sharing_writeup.Rmd` | Source for the write-up |
| `bike_sharing_writeup.docx` | The write-up (no R code) |
| `makefile` | `make all` rebuilds the .html and .docx |

Needs `tidyverse`, `broom`, `knitr` and `rmarkdown`.
